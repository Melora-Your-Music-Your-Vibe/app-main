================================================================================
                        MELORA - YOUR MUSIC, YOUR VIBE
                    Personal Music Streaming Web Application
================================================================================

PROJECT OVERVIEW
================================================================================
Name: Melora
Tagline: Your Music, Your Vibe
Description: A personal, ad-free music streaming web application optimized for 
             Android and iOS devices, providing Spotify-like experience with 
             5000+ songs hosted on free cloud infrastructure.

Target Platform: Progressive Web App (PWA) - Mobile-First Design
Tech Stack: React.js (Frontend) + Node.js/Express (Backend)
Purpose: Personal music streaming without advertisements


================================================================================
                            TECHNOLOGY STACK
================================================================================

FRONTEND
--------
- Framework: React 18.x with Vite
- Routing: React Router DOM v6
- State Management: Zustand / Redux Toolkit (choose one)
- UI Framework: Tailwind CSS + shadcn/ui components
- Audio Player: Howler.js or react-h5-audio-player
- HTTP Client: Axios
- PWA: Vite PWA Plugin (workbox)
- Icons: Lucide React / React Icons
- Animations: Framer Motion (optional)
- Build Tool: Vite

BACKEND
-------
- Runtime: Node.js v18+
- Framework: Express.js
- Database: MongoDB with Mongoose ODM
- Authentication: JWT (JSON Web Tokens)
- File Upload: Multer
- Cloud Storage: Cloudinary SDK / AWS S3
- Security: Helmet, CORS, express-rate-limit
- Validation: Joi / express-validator
- Environment: dotenv
- Process Manager: PM2 (for production)

DATABASE
--------
- Primary: MongoDB Atlas (Free Tier: 512MB)
- ORM: Mongoose

CLOUD STORAGE
-------------
- Audio Files: Cloudinary (Free: 25GB) or Backblaze B2
- Thumbnails: Cloudinary

HOSTING
-------
- Frontend: Vercel / Netlify
- Backend: Render / Railway / Cyclic
- Database: MongoDB Atlas (Cloud)

================================================================================
                          DATABASE SCHEMA DESIGN
================================================================================

1. SONGS COLLECTION
-------------------
{
  _id: ObjectId,
  title: String (required, indexed),
  artist: String (required, indexed),
  artistId: ObjectId (ref: 'Artist'),
  album: String (required),
  albumId: ObjectId (ref: 'Album'),
  genre: String (indexed),
  year: Number,
  duration: Number (in seconds),
  audioUrl: String (required) - Cloudinary URL,
  thumbnailUrl: String (required) - Album art,
  lyrics: String (optional),
  language: String,
  playCount: Number (default: 0),
  isFavorite: Boolean (default: false),
  tags: [String],
  fileSize: Number (in bytes),
  bitrate: String (e.g., "320kbps"),
  createdAt: Date,
  updatedAt: Date
}

Indexes:
- title (text index for search)
- artist (text index for search)
- genre
- playCount (descending for popular songs)


2. PLAYLISTS COLLECTION
-----------------------
{
  _id: ObjectId,
  name: String (required),
  description: String,
  coverImage: String (URL),
  songs: [ObjectId] (ref: 'Song'),
  songCount: Number (default: 0),
  totalDuration: Number (in seconds),
  isPublic: Boolean (default: false),
  createdAt: Date,
  updatedAt: Date
}


3. ARTISTS COLLECTION
---------------------
{
  _id: ObjectId,
  name: String (required, unique, indexed),
  bio: String,
  profileImage: String (URL),
  genre: [String],
  socialLinks: {
    spotify: String,
    youtube: String,
    instagram: String
  },
  songCount: Number (default: 0),
  albumCount: Number (default: 0),
  createdAt: Date,
  updatedAt: Date
}


4. ALBUMS COLLECTION
--------------------
{
  _id: ObjectId,
  title: String (required, indexed),
  artist: String (required),
  artistId: ObjectId (ref: 'Artist'),
  year: Number,
  genre: String,
  coverImage: String (URL),
  totalTracks: Number,
  totalDuration: Number (in seconds),
  songs: [ObjectId] (ref: 'Song'),
  createdAt: Date,
  updatedAt: Date
}


5. RECENTLY PLAYED COLLECTION
-----------------------------
{
  _id: ObjectId,
  songId: ObjectId (ref: 'Song', required),
  playedAt: Date (default: Date.now),
  deviceInfo: String (optional)
}

Indexes:
- playedAt (descending)
- Compound index: songId + playedAt


6. FAVORITES COLLECTION (Alternative to boolean in Songs)
---------------------------------------------------------
{
  _id: ObjectId,
  songId: ObjectId (ref: 'Song', required),
  addedAt: Date (default: Date.now)
}

                          API ENDPOINTS DOCUMENTATION
================================================================================

BASE URL: http://localhost:5000/api/v1
Production: https://melora-api.onrender.com/api/v1


SONGS ENDPOINTS
---------------

1. GET /songs
   Description: Get all songs with pagination
   Query Params:
     - page (default: 1)
     - limit (default: 20)
     - genre (optional)
     - year (optional)
     - artist (optional)
     - sortBy (playCount | createdAt | title) (default: createdAt)
     - order (asc | desc) (default: desc)
   Response: {
     success: true,
     data: [...songs],
     pagination: {
       currentPage: 1,
       totalPages: 10,
       totalSongs: 200,
       hasMore: true
     }
   }

2. GET /songs/:id
   Description: Get single song details
   Response: {
     success: true,
     data: {song object}
   }

3. POST /songs
   Description: Upload a new song (Admin only for now)
   Content-Type: multipart/form-data
   Body:
     - audioFile (file)
     - thumbnail (file)
     - title
     - artist
     - album
     - genre
     - year
     - lyrics (optional)
   Response: {
     success: true,
     message: "Song uploaded successfully",
     data: {song object}
   }

4. PUT /songs/:id
   Description: Update song metadata
   Body: {any song fields to update}
   Response: {
     success: true,
     message: "Song updated successfully",
     data: {updated song}
   }

5. DELETE /songs/:id
   Description: Delete a song
   Response: {
     success: true,
     message: "Song deleted successfully"
   }

6. GET /songs/popular
   Description: Get popular songs (sorted by playCount)
   Query Params:
     - limit (default: 20)
   Response: {
     success: true,
     data: [...popular songs]
   }

7. GET /songs/latest
   Description: Get latest added songs
   Query Params:
     - limit (default: 20)
   Response: {
     success: true,
     data: [...latest songs]
   }

8. PATCH /songs/:id/play
   Description: Increment play count
   Response: {
     success: true,
     message: "Play count updated"
   }

9. PATCH /songs/:id/favorite
   Description: Toggle favorite status
   Response: {
     success: true,
     data: {
       isFavorite: true/false
     }
   }

================================================================================
                        AUTHENTICATION (FUTURE PHASE)
================================================================================

NOTE: For personal use, authentication is NOT required initially.
      Implement when scaling to multi-user.

When implementing authentication:

1. USER MODEL
-------------
{
  _id: ObjectId,
  email: String (unique, required),
  password: String (hashed),
  name: String,
  profilePicture: String,
  createdAt: Date,
  lastLogin: Date,
  isAdmin: Boolean (default: false)
}

2. AUTH ENDPOINTS
-----------------
POST /auth/register - Register new user
POST /auth/login - Login user
POST /auth/logout - Logout user
GET /auth/me - Get current user
PUT /auth/update-profile - Update profile
PUT /auth/change-password - Change password
POST /auth/forgot-password - Forgot password
POST /auth/reset-password - Reset password

3. JWT IMPLEMENTATION
---------------------
- Access Token: 15 minutes expiry
- Refresh Token: 7 days expiry
- Store in httpOnly cookies
- Middleware: verifyToken

import axios from 'axios';

const API_BASE_URL = import.meta.env.VITE_API_URL || 'http://localhost:5000/api/v1';

const api = axios.create({
  baseURL: API_BASE_URL,
  timeout: 10000,
  headers: {
    'Content-Type': 'application/json',
  },
});

// Request interceptor
api.interceptors.request.use(
  (config) => {
    // Add auth token if available
    const token = localStorage.getItem('token');
    if (token) {
      config.headers.Authorization = `Bearer ${token}`;
    }
    return config;
  },
  (error) => Promise.reject(error)
);

// Response interceptor
api.interceptors.response.use(
  (response) => response.data,
  (error) => {
    // Handle errors globally
    const message = error.response?.data?.message || 'Something went wrong';
    return Promise.reject(message);
  }
);

export default api;

export const formatTime = (seconds) => {
  if (!seconds || isNaN(seconds)) return '0:00';
  
  const mins = Math.floor(seconds / 60);
  const secs = Math.floor(seconds % 60);
  return `${mins}:${secs.toString().padStart(2, '0')}`;
};

export const formatDuration = (seconds) => {
  if (!seconds || isNaN(seconds)) return '0 min';
  
  const hours = Math.floor(seconds / 3600);
  const mins = Math.floor((seconds % 3600) / 60);
  
  if (hours > 0) {
    return `${hours} hr ${mins} min`;
  }
  return `${mins} min`;
};


FORMAT DATE (utils/formatDate.js)
---------------------------------
export const formatDate = (date) => {
  return new Date(date).toLocaleDateString('en-US', {
    year: 'numeric',
    month: 'short',
    day: 'numeric'
  });
};

export const getRelativeTime = (date) => {
  const now = new Date();
  const diff = now - new Date(date);
  const seconds = Math.floor(diff / 1000);
  const minutes = Math.floor(seconds / 60);
  const hours = Math.floor(minutes / 60);
  const days = Math.floor(hours / 24);
  
  if (days > 0) return `${days} day${days > 1 ? 's' : ''} ago`;
  if (hours > 0) return `${hours} hour${hours > 1 ? 's' : ''} ago`;
  if (minutes > 0) return `${minutes} minute${minutes > 1 ? 's' : ''} ago`;
  return 'Just now';
};

export const storage = {
  set: (key, value) => {
    try {
      localStorage.setItem(key, JSON.stringify(value));
    } catch (error) {
      console.error('Error saving to localStorage:', error);
    }
  },
  
  get: (key) => {
    try {
      const item = localStorage.getItem(key);
      return item ? JSON.parse(item) : null;
    } catch (error) {
      console.error('Error reading from localStorage:', error);
      return null;
    }
  },
  
  remove: (key) => {
    try {
      localStorage.removeItem(key);
    } catch (error) {
      console.error('Error removing from localStorage:', error);
    }
  },
  
  clear: () => {
    try {
      localStorage.clear();
    } catch (error) {
      console.error('Error clearing localStorage:', error);
    }
  }
};
